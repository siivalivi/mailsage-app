# **App Name**: MailSage

## Core Features:

- Email Summarization: Summarize emails in the user's Gmail inbox using natural language processing. The tool will shorten emails while preserving important context and action items.
- Natural Language Querying: Query emails using natural language. The tool will retrieve relevant emails based on user queries, such as 'find emails about the Smith project from last week'.
- Email List Display: Display a list of emails with sender, subject, and a preview of the summary.
- Email View: Display the full email content alongside the summary.
- Google Authentication: Enable users to authenticate with their Google account to access Gmail.

## Style Guidelines:

- Primary color: Muted purple (#8E7AB5) to evoke thoughtfulness and efficiency.
- Background color: Very light grey (#F5F4F7).
- Accent color: Dusty blue (#6A8CAF) for interactive elements and call-to-actions.
- Headline font: 'Poppins' (sans-serif) for a geometric, contemporary, fashionable look, best suited to headlines and short paragraphs of text.
- Body font: 'Inter' (sans-serif) for a modern, objective, neutral, readable style.
- Use simple, minimalist icons to represent actions such as summarizing, querying, and authenticating.
- Use a clean, card-based layout for displaying emails and summaries.
